# Business Insights Engine

## Overview

A Business Intelligence project built using PostgreSQL and Power BI to analyze Global Superstore sales data and generate actionable business insights.

## Tools & Technologies

* PostgreSQL
* SQL
* Power BI
* Global Superstore Dataset

## Project Workflow

1. Data Import into PostgreSQL
2. Data Cleaning and Validation
3. Business Analysis using SQL
4. Dashboard Development in Power BI
5. Insight Generation

## Dashboard 1: Executive Business Dashboard

* Total Sales
* Total Profit
* Profit Margin
* Total Orders
* Total Quantity
* Sales by Region
* Profit by Region
* Sales Trend Analysis
* Category Analysis

## Dashboard 2: Product & Customer Analysis

* Top 10 Products by Sales
* Top 10 Products by Profit
* Top 10 Customers by Sales
* Sales vs Profit Analysis
* Customer Segment Analysis

## Key Business Insights

* Identified high-performing regions.
* Compared profitability across regions.
* Evaluated customer segment performance.
* Identified top revenue-generating products.
* Analyzed sales and profit relationships.

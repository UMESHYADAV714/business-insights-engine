# Business Insights Engine

## Project Overview

Business Insights Engine is an end-to-end Business Intelligence and Analytics project that transforms raw sales data into actionable business insights.

The project combines SQL, Power BI, Python Analytics, AI-driven insights, Flask Web Application, Automated PDF Reporting, and Email Alert Automation into a single business intelligence solution.

---

## Features

### Phase 1: Data Warehouse & Dashboard

- Data Cleaning using SQL
- PostgreSQL Database Integration
- Business KPI Analysis
- Power BI Interactive Dashboard

### Phase 2: Python Analytics Layer

- Sales Analysis
- Profit Analysis
- Monthly Trend Analysis
- Automated Chart Generation

### Phase 3: AI Insight Generation

- Automated Business Insight Creation
- KPI Summary Generation
- Performance Analysis

### Phase 4: Flask Web Application

- Interactive Dashboard
- KPI Cards
- Dynamic Charts
- Web-based Reporting Interface

### Phase 5: Automated Reports & Alerts

- PDF Report Generation
- Email Report Delivery
- Scheduled Report Automation

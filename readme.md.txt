 Business Insights Engine
Project Overview
This project analyzes Global Superstore sales data using PostgreSQL and Power BI.

 Tools Used
- PostgreSQL
- SQL
- Power BI

Dashboard Features
- Total Sales
- Total Profit
- Profit Margin
- Sales by Region
- Profit by Region
- Sales Trend Analysis
- Top 10 Products by Sales
- Top 10 Products by Profit
- Top 10 Customers by Sales
- Sales vs Profit Analysis
